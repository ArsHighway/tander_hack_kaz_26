# Сценарии показа

Стенд — справочник стандартов портала (`CATALOG_PATHS=data/catalog/standards.json`, `EXEMPLARS_PATH`,
`KTRU_PATHS`, `TWINS_PATH` — как в `.env`): 8 569 категорий «Товаров» с путём, кодами КПГЗ и ОКПД2, характеристиками и
«Общими сведениями» (производитель, модель, страна). Готовых примеров на экране нет: поставщик вставляет свой
текст или файл. Тексты для показа — `docs/demo-texts.txt`.

Стенд на другой машине — из архива `tenderhack-kazan-stand-20261010.zip` (README, «Данные стенда»): в нём уже
справочник, похожие СТЕ с характеристиками и векторами, двойники, векторы справочника и кэш картинок. Шаги сборки
ниже (`index_catalog`, `build_exemplar_values`, `build_twins`) нужны только после пересборки данных.

Перед каждым показом, на том же стенде:

```bash
docker compose up -d --build
docker compose exec api python -m app.tools.index_catalog       # векторы справочника (после смены CATALOG_PATHS; со стендом из архива — загрузка из него)
docker compose exec api python -m app.tools.evaluate            # «Метрики»
cd backend && uv run python -m app.tools.build_exemplar_values ../data/catalog/exemplars.jsonl  # подсказки похожих СТЕ (после build_exemplars)
cd backend && uv run python -m app.tools.build_twins             # двойники «такая СТЕ уже есть» (~8 мин, после fetch_ste)
cd backend && uv run python -m app.tools.warm_images --texts ../docs/demo-texts.txt   # миниатюры похожих СТЕ в кэш
cd frontend && npm run e2e                                      # сквозные сценарии ниже; любой FAIL — не показывать
playwright-cli --raw run-code --filename=e2e/wizard.js          # регрессии мастера: сброс, запросы в полёте, повторные ответы
```

Для отправки нужен файл фото товара (JPEG, PNG или WebP до 5 МБ): на портале изображение у товара обязательно,
без фото мастер не отправит. Держать его под рукой.

Портал отвечает медленно (GetSku 6–27 с, 07.10.2026): миниатюры, которых нет в кэше, при первом показе вопроса
не появляются и докачиваются в фоне. Прогрев перед показом — обязателен.

## 0. Категории хакатона: инструменты, мебель, одежда (09.10.2026)

Проверено на стенде 09.10 (справочник КТРУ из XML ЕИС, похожие СТЕ с синтетикой, векторы). Наименование —
первой строкой поля, описание — со второй.

1. **До итогового кода КТРУ без вопросов, источник у полей.**
   - `Молоток слесарный 500 г` / `Рукоятка из фибергласса, длина 320 мм. Ручка противоскользящая: да` —
     «Молотки», КТРУ 25.73.30.141-00000012; у «Длина рукоятки» и «Тип» пометка «КТРУ»; «Ручка
     противоскользящая: да» — в блоке «Вне шаблона категории» с пометкой «новая» (её нет ни в КТРУ, ни на
     портале — организаторы просили не выбрасывать); замечание «В наименовании «500 г»» с исправлением.
   - `Сварочный аппарат инверторный Ресанта САИ-190` / `Ток сварки 10-190 А, электроды 1,6-5 мм, напряжение
     220 В` — КТРУ 27.90.31.110-00000001, максимальный ток и тип источника питания — из КТРУ.
   - `Шкаф для одежды металлический двухсекционный ШРМ-22` / `Высота 1860 мм, ширина 600 мм, глубина 500 мм,
     замок, полка для головных уборов, цвет серый` — КТРУ 31.01.11.121-00000003, размеры и цвет из текста.
2. **Категория сама, КТРУ сужается вопросом.**
   - `Жилет сигнальный оранжевый 2 класса защиты` / `Световозвращающие полосы, размер XL` — «Одежда
     специальная повышенной видимости»; класс 2 из текста уже сузил позиции КТРУ, второй этап спрашивает
     только «Половая принадлежность» (было 6 позиций — осталось 2).
   - `Ключ разводной 250 мм` / `Максимальный развод губок 30 мм, сталь CrV, обрезиненная рукоятка` —
     «Ключи гаечные разводные», вопрос «Тип исполнения» из двух позиций КТРУ.
3. **Разговорный и неполный ввод.**
   - `Болгарка Bosch GWS 750-125` / `Угловая шлифмашина, диаметр диска 125 мм, мощность 750 Вт` — словарь
     раскрывает «болгарку» как угловую шлифовальную машину: первой предлагается «Шлифмашины», мощность и
     диаметр диска — из текста с пометкой «КТРУ».
   - `курт мужск зимн` — опечатки и обрывки: модуль предлагает выбрать из шести категорий (куртки для взрослых
     с верхом из меха, из текстильных материалов…), а не спрашивает «Подкладку»; блокирующее «нужно не меньше
     4 характеристик» объясняет, что дописать.

Слабое место (не показывать): «Стул офисный на металлическом каркасе… сиденье и спинка из фанеры» — значение
перечня, найденное в тексте, ложится во все поля с этим значением: «фанера» попадает в каркас, «металл» — в
сиденье. Правка по соседним словам проверена и откатана: на отложенной выборке она убирала больше верных
значений, чем неверных.

## 1. Мастер: вопрос категории → вопрос КТРУ → характеристики (Т2.4, Т2.5)

1. «Создание СТЕ» → «Зерно пшеницы продовольственное, ГОСТ 9353» → «Заполнить карточку» (`Ctrl Enter`).
   Без ГОСТ модуль сам выбирает «Корма для парнокопытных» (71 % похожих: на портале пшеницу чаще продают
   как корм) — тоже можно показать: шаг 2 открывается из полосы шагов, категория меняется.
2. Шаг 2: несколько категорий разных товаров, у каждой код, «Совпадение N %» (доля голоса 30 похожих СТЕ) и
   миниатюры похожих СТЕ портала. Клавиши 1…6 выбирают вариант, Enter подтверждает. Есть «Ни одна не
   подходит». Категория с совпадением от 70 % выбирается сама, шаг 2 тогда пройден без вопроса.
3. Шаг 3: «Уточните «Наименование типа»» — шесть позиций КТРУ категории, у каждой код и «останется 1 позиция».
4. Шаг 4: позиция 01.11.10.000-00000003 в полосе шагов и в живой карточке справа. Изменившиеся после ответа
   строки карточки на секунду подсвечены. Пройденный шаг открывается из полосы шагов, ответ можно изменить.
5. То же на главном товаре: «Бумага для офисной техники Снегурочка А4, плотность 80 г/м2, 500 листов, белизна
   146%» — категория сама (97 %), в карточке формат, плотность, белизна, листы, производитель; шаг 3 —
   «Уточните «Марка бумаги»» среди шести позиций КТРУ бумаги (17.12.14.110-…).

## 2. Категория без вопроса, позиция КТРУ из текста, отправка и модерация (Т3)

1. «Смеситель для кухни однорычажный с выдвижной лейкой, хром, латунь, керамический картридж 35 мм»: категория
   «Смесители водоразборные» определена сразу (совпадение выше 70 %), позиция КТРУ 28.14.12.110-00000019
   «Смеситель водоразборный» — по «однорычажный» → «Тип управления: Рычажный», мастер сразу на шаге 4.
   Значения из текста — жёлтым, под полем откуда взято. Без «однорычажный» совпадение у единственной
   категории ниже 70 %: модуль не ставит код сам, а просит подтвердить позицию или «Ни одна не подходит».
2. Шаг 4: «Общие сведения» (фото — «обязательно»: без него мастер не отправит; производитель, модель, страна —
   подсказки из СТЕ категории, не ограничение), обязательные, найденные в тексте значения — на виду, пустые
   необязательные свёрнуты за «Показать ещё». Фрагмент во вкладке «Ваш текст» ведёт к полю. У смесителя три
   обязательные характеристики позиции КТРУ, «Готово 2 из 3»: «Материал: латунь» и «Тип управления:
   Однорычажный» — из текста, жёлтым («однорычажный» — то же, что «Рычажный» в КТРУ, замечания нет). Их
   подсказали похожие СТЕ, а текст подтвердил: такая подсказка сразу значение из текста. «Монтаж» текст не
   называет: поле пустое, под ним «Подсказка: как у 7 из 9 похожих СТЕ портала с этим полем» и кнопка
   «Принять «на горизонтальную поверхность»» (не жёлтым — это не текст поставщика). После «Принять» под полем
   сначала сведения КТРУ — «В позиции КТРУ 28.14.12.110-00000019 это записано иначе: «Внутренний (скрытый)»,
   «Наружний»», за ними «Принято из подсказки: как у 7 из 9 похожих СТЕ портала с этим полем»: можно выбрать
   своё значение из списка. У необязательных — «Принять все 6 подсказок». В карточку, проверку и
   заявку идёт только принятое. У числа в единице позиции — короткая запись рядом: «мм = 1,5 м».
   Если всё заполнено из текста и подсказок нет, мастер сразу открывает шаг 5 — шаг 4 доступен из полосы шагов.
   Пока фото нет, «Осталось заполнить» начинается с «Фото товара» (ссылка ведёт к кнопке «Загрузить фото»).
3. Шаг 5 («Проверить и отправить»; без подсказок мастер открыл бы его сам): цепочка кодов, значения в формате КТРУ
   («≥ 80 и < 90»), единицы ЕИС. Фото ещё нет — красная плашка «Отправить пока нельзя. Заполните: Фото товара»:
   на портале изображение у товара обязательно. **Файл фото держать под рукой** (JPEG, PNG или WebP до 5 МБ).
   Не хватает только фото — в плашке кнопка «Загрузить фото»: файл уходит сразу, карточка проверяется заново,
   человек остаётся на шаге 5. Другой путь — ссылка «Фото товара» или «Отправить»: шаг 4, фокус на кнопке фото,
   загрузить, «Проверить и отправить». С фото красной плашки нет, у смесителя остаётся оранжевая «Проверьте перед
   отправкой: В наименовании «35 мм»» — отправить можно. Пустые обязательные тоже дали бы красное «Заполните: …»,
   и «Отправить» повела бы к первому такому полю. «Как на портале» — карточка в разметке страницы СТЕ.
   «Отправить на модерацию» → «Заявка № N у модератора».
4. «Мои заявки» → заявка «на модерации» (с миниатюрой фото). Переключатель «Модератор»: та же карточка только
   для чтения, нарушения на полях, «Вернуть с замечаниями»; рядом с кодами — названия: «Позиция КТРУ
   31.01.10.000-00000005 · Стол письменный», у категории — путь в каталоге. Заявки без замечаний модуля (ни
   блокирующих, ни предупреждений, в том числе по позиции КТРУ) помечены в очереди «без замечаний модуля»:
   «Одобрить чистые (N)» открывает список этих N заявок, «Одобрить N» одобряет ровно их с записью в журнале
   заявки, «Отмена» — ничего; у остальных над решением — «Почему не в один клик: …» (у смесителя — «В
   наименовании «35 мм»», замечание по позиции КТРУ — первым). Поставщик → «Исправить»: мастер с заявкой, «Замечания
   модератора»; вопросы, на которые заявка уже отвечала, мастер не задаёт заново. После отправки заявка снова
   ждёт решения.

## 2а. Такая СТЕ уже есть на портале

«Концентрированный усилитель стирки от жировых и масляных загрязнений с инновационной системой оптического
осветлителя ДЕРВАЛ БРАЙТ» — так на портале уже названы две СТЕ. Категория «Усилители стирки белья» — без вопроса,
над полями — «Такие СТЕ уже есть на портале» со ссылками на обе, под наименованием — замечание правила
модерации: заявку-дубль отклонят с причиной «Предложена другая СТЕ» (статья базы знаний портала 214102). Над
полями — «Полей с подсказкой СТЕ портала: 13. В карточку попадёт только то, что вы примете.» Тринадцать полей,
которых нет в тексте, пустые, под каждым «Подсказка: как у 2 из 2 таких же СТЕ портала с этим полем» и «Принять
«Жидкость»», у необязательных — «Принять все 12 подсказок» (производителя «ТЕКСКЕПРО» принимают у поля). Описания
нет, поэтому модель о них не спрашивают: на отложенной выборке значения такой же СТЕ верны в 95 %. Без «Принять»
в карточке ни одной характеристики: шаг 5 скажет «В карточке 0 характеристик, нужно не меньше 4». Если поправить
наименование, блок и замечание о дубле пропадут вместе. То же замечание видит модератор (`/check`) и строка
пакета.

## 3. Файл вместо текста (Т6)

1. Шаг 1 → `backend/tests/fixtures/docs/spec.docx` (или `spec.pdf`): текст встаёт в поле, заполнение — по
   кнопке человека. Скан без текста (`scan.pdf`) — «В PDF нет текстового слоя».
2. `goods.docx` (таблица на 6 товаров): «В «goods.docx» 6 товаров» → «Открыть массовую загрузку» — пакет сразу в
   работе, «Открыть в форме» у строки открывает мастер с её характеристиками.

## 4. Метрики (Т5) и API

«Метрики»: первым блоком — отложенная выборка СТЕ портала (2 000 СТЕ, вынутых вместе с двойниками из
справочника и похожих СТЕ; в индексе двойников остаются двойники выборки, как у новой карточки; векторный
поиск включён, LLM — нет): категория первой 69,0 %, среди пяти 81,9 %, без вопроса 49,9 % с точностью 85,8 %,
уверенных ошибок 7,1 %; чего нет в тексте, заполнено верно 18,1 % при точности 76,7 % (было 5,0 % и 61,9 %),
значения такой же СТЕ верны в 94 %, характеристик вручную — 3,5 на СТЕ, без единого действия — 32,7 %, ответ
шага — 0,42 / 0,81 с (медиана / 95-й перцентиль), дольше 7 с — ни одного. Ниже — золотой набор на демо-справочнике (подписан как синтетика) и живые карточки
портала. У каждой цифры выборка и способ расчёта. «API»: поток, методы, настоящие примеры запроса и ответа, Swagger, BPMN.

## 5. Неоднозначный товар

«Мешки для мусора 120 л»: четыре категории с процентами совпадения — мешки полимерные 53 %, мешки бумажные
16 %, пакеты полимерные 15 %, контейнеры для отходов 13 %; ни одна не набирает 70 %, модуль спрашивает
«Материал» и показывает, сколько вариантов останется после ответа.

## 6. Вне справочника

«Ремонт автомобиля» → «Категория не найдена» с похожими позициями справочника; в живой карточке коды не «ждут
ответа», а отсутствуют.
