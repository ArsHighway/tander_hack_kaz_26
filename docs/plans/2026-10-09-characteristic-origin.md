# Источник характеристики: КТРУ, портал, новая (09.10.2026)

Устное требование организаторов на открытии (`docs/tz/01-methodology.md`, «Устные уточнения»): характеристики
унифицируются в порядке КТРУ → как пишут на портале → новое разумное свойство; ничего не выбрасывать и помечать
в интерфейсе, какая характеристика из КТРУ, какая портальная, какая новая. До этого модуль заполнял только
шаблон категории портала, а свойства из текста вне шаблона терял (42 % характеристик поставщика на отложенной
выборке категорий хакатона).

## Решения

- **Пометка шаблона.** `CharacteristicOut.origin`: `ktru` — имя характеристики есть у позиции КТРУ (итоговой,
  а пока её нет — у любой позиции КТРУ, привязанной к категории); `portal` — только в шаблоне категории.
  Сверка по имени (`fold`): у привязанных категорий хакатона 97,5 % характеристик КТРУ есть в шаблоне по имени.
- **Характеристики КТРУ вне шаблона** (2,5 %) при итоговом коде КТРУ дописываются в `characteristics` с
  `origin: ktru`; значение — правилами по тексту и ответами второго этапа.
- **Свойства вне шаблона** — `AutofillOut.extra`. Пары «метка: значение» из описания (строки, «;», «|»,
  запятая перед следующей «Метка:») и «метка значение» без двоеточия, если метка — известное имя
  характеристики портала (формат листа 1 выгрузок). Метка из шаблона или КТРУ (с синонимами стандарта) —
  не лишняя, её заполняют правила. Известна порталу по любой категории — `origin: portal`, имя в самом
  частом написании портала. Иначе — `origin: new`, имя как у поставщика. Отбрасываются служебные метки
  («Описание», «Примечание»), общие сведения (производитель, модель, страна), мат, метки без слова из трёх
  букв; не больше 15 на карточку.
- **Проверка.** `CharIn.origin` (и в заявке). Характеристики нет в позиции: `ktru` — не замечание (её
  сверяет `ktru_value_issues`), `portal`/`new` — `info` «новая характеристика, модератор проверит
  формулировку»; без `origin` — прежний `warn`.
- **Интерфейс.** У поля из КТРУ в подписи «КТРУ»; свойства вне шаблона — отдельный блок шага 4 «Вне шаблона
  категории» с подписью «Так пишут на портале» или «Новая характеристика»; в карточку и заявку они идут со
  своим `origin`.

## Проверка

- Тесты: разбор пар, классификация, пометка `origin`, `info` вместо `warn`, KTRU-only характеристики.
- `evaluate_holdout` на категориях хакатона — метрики не падают; доля «характеристик поставщика, которые
  попали в карточку» (в шаблон или вне его) растёт.
- e2e мастера на :8080.
