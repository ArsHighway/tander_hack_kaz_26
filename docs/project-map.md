Хакатон 09–11.10.2026 (разработка 21:00 09.10 — 13:00 11.10), кейс «Автозаполнение ключевых характеристик в СТЕ».
Методичка и данные выданы 09.10 в 19:00: категории хакатона — **одежда, мебель, инструменты**, превалирует справочник
КТРУ (XML ЕИС, только `actual`). ТЗ — `docs/tz/` (методичка, критерии с баллами, чек-лист, данные), ресерч —
`docs/research/`. Сначала читать их, а не код.

КТРУ; потоки A–F с владельцами файлов и приёмкой. Чужой файл — только по правилу из его раздела 5.

## Правила хакатона

- **Ограничения методички**: Linux и веб-интерфейс; без платных поисковых API (Yandex Search API, Google Custom
  Search JSON API); без low-code и no-code. Критерии и баллы — `docs/tz/02-criteria.md`; UI — «с сохранением
  цветовой схемы и разметки страницы Портала поставщиков» (UI-кит Figma в `docs/tz/01-methodology.md`; значения
  кита — `data/figma/portal-kit.md`). Доска организаторов только для просмотра: копия в черновиках команды
  (`ZD2zYkTR4IcfN6iuFxB36I`) с правом правки, значения снимаются Plugin API `figma.*` в консоли её вкладки через
  расширение Chrome; MCP Figma на Starter — 6 вызовов в месяц и требует права правки.
- **Защита**: этап 1 — презентация до 5 мин с BPMN, второй участник параллельно показывает реальные кейсы; этап 2 —
  ссылки на репозиторий, топ-5 защищаются 7 мин + 10 мин вопросов. Репозиторий смотрят — история коммитов видна.
- **LLM — локальная `gemma-4-31b-it-Q8_0.gguf` (решение 11.10.2026)**: llama.cpp server, сервис `llm` в compose
  (профиль `llm`, файлы — `models/`, `models/README.md`), протокол OpenAI-совместимый; чат и второй слой
  (`LLM_REVIEW_MODEL`) — одна и та же модель. Эмбеддинги — отдельный сервер `embed` с `bge-m3-Q8_0.gguf`
  (`EMBED_*`). Облачных API и Ollama в решении нет. Настройки — `.env` (`LLM_PROVIDER=openai`, `LLM_BASE_URL`,
  `LLM_CHAT_MODEL`, `LLM_MODEL_FILE`); с хоста серверы — `127.0.0.1:8081` и `:8082` (`localhost` теряет 2 с на
  IPv6). Модель на карточках портала с этим файлом не замеряли (замер 04.10 — `gemma4:31b` из Ollama API,
  `docs/model-choice.md`). Проверка — `uv run python -m app.tools.llm_smoke`.
- **Правила вывода LLM исполняет код**: ответ со схемой валидируется pydantic (`LLMOutputError` иначе), значения и
  единицы принимаются, только если есть в справочнике (КТРУ/ОКЕИ). Промпт — не гарантия.
- **Данные организаторов** — `data/organizers/Казань 2026/` (разбор — `docs/tz/04-data.md`): КТРУ XML ЕИС
  (`КТРУ/КТРУ xml.zip`, 184 вложенных zip; берём `nsiKTRUNew_all_actual_*.xml` — 81 465 позиций), примеры выгрузок
  `Инструменты/Мебель/Одежда.xlsx` (лист 1 — ~100 тыс. СТЕ, характеристики строкой «имя значение / …» без категории;
  лист 2 — типовые свойства категорий КПГЗ). Разведка формата — `uv run python -m app.tools.recon <путь>`; под
  новый формат — читатель в `app/ingest/readers.py` и тест с примером файла.
- **Эксперты говорят аббревиатурами.** Наш словарь — `backend/app/glossary/abbreviations.csv`; из их базы —
  `uv run python -m app.tools.mine_abbreviations <данные> --to-db` в таблицу `glossary_abbreviation`
  (`source`: seed / mined / manual). В промпт LLM идёт `Glossary.prompt_block(text)`, в эмбеддинги — `expand`.
- **Данные организаторов — только в `data/`** (в `.gitignore`), не коммитить. Данные прошлых хакатонов —
  `data/past/<город>/`.
- **Стенд у сокомандников** — архив `data/bundle/tenderhack-kazan-stand-20261010.zip` (готовый `.env` без ключа +
  `data/catalog`, `metrics`, `cache/images`, векторы справочника для pgvector), распаковка в корень клона; шаги —
  README, «Данные стенда». Все зипки хакатона — в папку «Tender» на Google Диске (`H:\Мой диск\Tender`, правила
  ). Стенд выдаёт «не найдено» почти на всё — он на демо-справочнике
  (пустые пути в `.env`). `.env` из архива от 10.10 написан под Ollama (`LLM_PROVIDER=ollama` код не принимает):
  блок `LLM_*` / `EMBED_*` заменить на блок из `.env.example`.
- **Свой тестовый набор с портала** — `uv run python -m app.tools.build_testset` (из `backend/`, ~10 мин):
  `data/testset/testset.xlsx` (листы «Все», «Лёгкие», «Средние», «Сложные», «Как считали»; колонки как у пермской
  выгрузки СТЕ + сложность) и `testset.jsonl` в формате `app.portal.cards`.
- **Датасет с портала** — `data/portal/` (01.10.2026, публичный API zakupki.mos.ru вне закрытого robots.txt `/api`):
  `skus.jsonl` 2 549 СТЕ из 43 областей с характеристиками, `skus_detailed.jsonl` 430 полных карточек, `stats.md`
  выводы. Скрипты `fetch_portal.py`, `fetch_details.py` (последовательно, пауза 0,8 с). В карточках портала нет КТРУ
  (0 из 430), описание есть у 7 %: вход «свободный текст» = наименование + описание.
  02.10.2026 `fetch_categories.py` докачал `categories.jsonl`: 6 329 СТЕ из 35 плотных категорий (бумага, батарейки,
  перчатки смотровые, картриджи по 300, ещё 25 самых наполненных по 200). Мешков для мусора отдельной категорией в
  дереве нет. Отчёт по ним — `uv run python -m app.tools.portal_report ../data/portal/skus.jsonl
  ../data/portal/categories.jsonl --out ../data/metrics/portal.json --catalog ../data/catalog/portal.json` (из
  `backend/`, ~2,5 мин): аудит модерации, заполнение против портала, справочник из 39 категорий (`CATALOG_PATHS`).
- Когда пользователь просит «потыкать» или «посмотреть глазами» — поднять решение и смотреть скриншотами через

## Команды

- Всё целиком: `docker compose up -d --build`; с моделью (NVIDIA GPU, `.gguf` в `models/`) —
  `docker compose --profile llm up -d --build`.
- Бэкенд: `cd backend && uv run pytest && uv run ruff check .`
- Фронт: `cd frontend && npm test && npm run build && npm run lint`
- Контракт изменился: `uv run python -m app.tools.export_openapi`, затем `npm run gen:api` (тест `test_openapi_snapshot_is_current` ловит забытое)
- Метрики: `docker compose exec api python -m app.tools.evaluate`; BPMN: `uv run python -m scripts.bpmn`
- После правки поиска, извлечения или сужения — `cd backend && uv run python -m app.tools.evaluate`: юнит-тесты не ловят
  ложные совпадения на товарах вне справочника (исправление опечаток «колёс» → «солев» нашла только оценка, порог уехал с 0,2)
- Проверка глупым и враждебным вводом: промпт агента-поставщика `docs/qa/supplier-fuzz-prompt.md`, итог `docs/qa/2026-10-02-supplier-fuzz-report.md`. Новое правило карточки — сначала прогнать по `data/portal/` на ложные срабатывания
- Секреты — только в `.env`; `.env.example` без реальных паролей.
