# Промпт генерации синтетических наименований СТЕ

Пакеты готовит `uv run python -m app.tools.synthetic_exemplars batches` (из `backend/`), проверяет и
дописывает в индекс похожих — `... merge`. 09.10.2026 по этому промпту 20 агентов (Claude Haiku, по агенту
на пакет из 10 категорий, только Read и Write) написали 9 789 строк для 196 редких категорий хакатона;
`merge` оставил 9 766. `<ROOT>` — корень репозитория, `<NN>` — номер пакета.

---

Ты генерируешь синтетические наименования товаров (СТЕ) для Портала поставщиков zakupki.mos.ru — для
категорий, где у нас мало живых примеров. По этим наименованиям модуль голосованием похожих СТЕ определяет
категорию товара по тексту поставщика. Плохие примеры (чужая категория, бессмыслица) испортят поиск, поэтому
точность важнее количества.

Вход: файл `<ROOT>/data/synthetic/input/batch_<NN>.json` — список категорий.
У каждой: `code` (код КПГЗ), `category` (название конечной категории), `path` (ветка каталога),
`characteristics` (характеристики категории и известные значения), `real_examples` (живые наименования СТЕ
этой категории, могут быть пустыми), `siblings` (соседние категории той же ветки — их товары генерировать
НЕЛЬЗЯ).

Для КАЖДОЙ категории напиши 50 строк:
- 40 наименований в стиле портала: тип товара + ключевые признаки + бренд/модель/артикул и размеры, как в
  `real_examples` и как пишут поставщики («Ключ трубный рычажный №2 КОБАЛЬТ 1,5" 245-123, CrV», «Пальто
  женское зимнее из натуральной кожи, р. 48, чёрное», «Стеллаж металлический для декораций 2000х1000х500 мм,
  5 полок»). Разнообразь: разные реальные бренды этого рынка (российские и зарубежные), модели, размеры,
  материалы, цвета, комплектации, длина строки от 3 до 18 слов. Значения бери правдоподобные, опирайся на
  `characteristics`.
- 10 коротких запросов, как их пишет обычный менеджер без опыта («пальто кожаное зимнее женское»,
  «ключ трубный 2 дюйма», «дрель ручная механическая для дерева»), без бренда, 2–7 слов, строчными или как
  попало, можно с одной-двумя опечатками.

Жёсткие правила:
1. Каждая строка — товар именно этой конечной категории. Признаки, которые отличают категорию от соседей
   (сезон, материал, пол, возраст, тип привода, назначение), должны совпадать с названием категории:
   для «Пальто для детей с верхом из меха зимние» — детское, меховое, зимнее; не демисезонное и не взрослое.
2. Не повторяй строки и не делай почти-дубликаты, отличающиеся одной цифрой. Не копируй `real_examples`
   дословно.
3. Не пиши название категории как есть и не пиши общие слова без товара («Инструмент», «Мебель»).
4. Только русский язык для слов (бренды и модели — латиницей, как в жизни).

Выход: для каждой категории — отдельный файл
`<ROOT>/data/synthetic/raw/<code>.jsonl` (имя файла — код категории
как есть, с точками), ровно 50 строк, каждая строка — JSON-объект в одну строку:
`{"code": "<code>", "name": "<наименование>", "kind": "portal"}` для 40 наименований и
`{"code": "<code>", "name": "<запрос>", "kind": "query"}` для 10 запросов. Пиши файл инструментом Write
целиком, по одному вызову на категорию. Никаких других файлов не создавай и ничего не меняй.

Перед записью каждого файла перечитай свои 50 строк и выкинь (замени) те, что нарушают правила 1–3.
В конце ответь одной строкой на категорию: код, сколько строк записано.
